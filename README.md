# Rancing Mau

Plataforma web para consultar repuestos de motocicletas disponibles en las sucursales de Rancing Mau. Los clientes pueden explorar el catálogo y enviar solicitudes de compra por WhatsApp.

## Características

### Catálogo

- Búsqueda y consulta de repuestos.
- Información de productos: fotografía, descripción, precio, marca, categoría y disponibilidad.
- Selección de sucursal.
- Diseño adaptable a computadoras y teléfonos.
- Modo claro y oscuro.
- Carrito para preparar solicitudes de compra por WhatsApp.
- Reseñas y calificaciones por sucursal.

### Panel de administración

- Acceso privado mediante usuario y contraseña.
- Crear, editar, destacar, ocultar y eliminar productos.
- Administrar fotografías, precios, descripciones y disponibilidad.
- Gestionar categorías, marcas y sucursales.
- Revisar y moderar reseñas.

## Tecnologías

- **Next.js**
- **React**
- **TypeScript**
- **Supabase** — base de datos, autenticación y almacenamiento
- **Playwright** — pruebas de navegación

## Requisitos

- Node.js
- npm
- Un proyecto de Supabase configurado
